# Initech Timesheet

Weekly timesheets for project teams.

This is the practice repo for the AI-ready repo workshop. The `start` branch is the
repo before setup; this branch (`finished`) is the result. Follow [WORKBOOK.md](WORKBOOK.md).

## Running

    npm install
    cp .env.example .env
    npm run dev

## Verifying a change

    npm run verify

Runs lint, then type-check, then tests, and stops at the first failure.
